# 📊 Twitter Sentiment Analysis App

A machine learning web application built with **Python**, **Scikit-Learn**, and **Streamlit** to analyze the sentiment of tweets (Positive vs. Negative) in real-time.

---

## 🚀 Features
* **Real-time Prediction:** Enter any text or tweet, and the model instantly predicts its sentiment.
* **Trained Model:** Utilizes a **Multinomial Naive Bayes** classifier combined with **TF-IDF Vectorizer** for text processing.
* **Interactive UI:** Designed with an easy-to-use and clean user interface powered by Streamlit.

---

## 🛠️ Tech Stack
* **Python** (Programming Language)
* **Streamlit** (Web Framework)
* **Scikit-Learn** (Machine Learning Library)
* **Joblib** (Model Serialization)
